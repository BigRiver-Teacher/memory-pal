## 二、写入链路

记忆不是直接 `insert` 进表的，而是复用已经上线的接口，避免在脚本里复制一份
embedding 与结构化提取逻辑：

```
POST {站点}/api/memory   { "patientId": "...", "content": "..." }
   └─ DeepSeek  结构化提取 → entities / emotion / confidence / source_text
   └─ SiliconFlow BAAI/bge-m3 → 1024 维 embedding
   └─ insert into public.memories
```

两个要点：

- **幂等**：服务端会先按 `(patient_id, content)` 查重，重复内容返回
  `duplicate: true`，脚本可以反复执行而不会产生重复行。
- **低置信度拦截**：`confidence < 0.5` 时接口返回 202 且**不写库**，
  脚本会把这类结果单独报出来（本次 0 条）。

## 四、怎么查询这些数据

1. **网页端（最直观）**
   登录 `13800000000 / 123456` → 底部导航「长辈」→ 点「大肥鱼」切换为当前长辈
   → 回到「记忆」页即可看到 34 条记忆、情绪标签、实体和「被问次数」。
   前端走的接口是 `GET /api/memory?patientId=50b2d952-b4af-4ad6-a84b-3822989ee9bf`。
2. **接口直查**
   `GET {站点}/api/memory?patientId=50b2d952-b4af-4ad6-a84b-3822989ee9bf`
   返回 `{ memories: [...] }`，按 `created_at` 倒序。
3. **问答查询（患者端）**
   `POST {站点}/api/chat`，body `{ "patientId": "...", "message": "我老伴叫什么名字？" }`。
   `match_memories` 会按余弦相似度取回 Top5，相似度低于 0.5 的记忆不参与回答。
4. **日报与导出**
   `GET /api/report`（当日对话 + 记忆统计）、`GET /api/export`（Markdown 导出）。

## 六、顺带修掉的两个缺陷

这两处修复都在 `web/src/app/api/chat/route.ts`：

1. **个人日期事实被当成"系统日期问题"**
   `isExplicitDateQuestion` 只看「几号 / 几月几 / 星期几 / 几点」，
   于是「我生日是几月几号？」被判定为纯日期问题，**整条记忆检索分支被跳过**，
   只拿系统日期作答，必然答「记不太清了」。
   修复：新增 `PERSONAL_FACT_PATTERN`（生日/纪念日/体检/安排/来访/过节…），
   命中这类词就不再走纯日期捷径，回到记忆检索。
2. **实体过滤把最相似的记忆一起丢掉**
   `filterMemoriesByIntent` 在判定 `person` / `location` 意图后，只保留实体命中
   的记忆。问「我养的那只鸟**叫什么**？」会被规则判成 `person`，而鸟的记忆
   实体是「鸟/小黄/八哥」，不匹配人物词表 → 该条被丢弃 → 模型手上只剩家人的
   记忆，只能**编一个名字**（实测编出了「小灰」）。
   修复：`memories[0]`（最相似的那条）始终保留，实体过滤只做"优先挑出"，
   不再造成证据丢失。

## 七、复现命令

```bash
cd web

node scripts/seed-memories.mjs --dry-run                      # 先看要写什么
node scripts/seed-memories.mjs                                # 写入 34 条（幂等）
node scripts/seed-memories.mjs --chat-only                    # 只跑问答自检
node scripts/seed-memories.mjs --site=http://localhost:3000    # 指定站点（默认线上）
```

`--site` 指向本地 `next dev` 时，本地进程需要能读到
`SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` / `SILICONFLOW_API_KEY` /
`DEEPSEEK_API_KEY` / `QWEN_API_KEY`（Windows 用户环境变量或 `web/.env.local`）。

回归测试：`npm test`（118 项全绿），其中
`tests/seed-memories-script.test.mjs` 管住种子数据的条数与唯一性，
